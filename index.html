The studio

One studio,
every genre.

Dusk Games Interactive is an independent studio built on range rather than a formula — 2D platformers, 2.5D shooters, atmospheric horror, and adventure titles all live in the same catalog.

Some started as weekend game jams, some as first projects, some as full atmospheric builds. What ties them together isn't genre — it's a studio willing to build whatever the idea actually calls for.
